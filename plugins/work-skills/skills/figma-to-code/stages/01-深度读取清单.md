# 第一阶段深度读取清单

仅在复杂页面、深度读取、根响应截断或结构/视觉冲突时加载。它扩展 `01-读取并规划当前画板.md` 的 P4，不改变第一阶段只读边界。

## P4.1 图层树与布局

递归覆盖 Frame 下全部节点：

- 节点 ID、名称、类型、可见性、父子关系、同级顺序、绝对/相对 bbox、裁切和溢出；
- Auto Layout 方向、对齐、gap、padding、尺寸模式、约束和响应行为；
- 组件/实例/变体、属性、override、变量及绑定值；
- section 归属、UI 角色、实现角色和视觉 z-index；
- 隐藏层、辅助层、蒙版外内容和布尔减除内容的最终可见性依据。

每个图层必须归入一个 section，并标记视觉角色。`unknown_role` 必须说明原因并进入复核清单。

## P4.2 文本

逐个文本层读取完整内容、文本/视觉 bbox、行数、换行、字体、字号、字重、行高、字距、对齐、装饰和溢出。下钻 run/span 并记录局部 fill、stroke、opacity、倾斜、阴影和发光；区分字形斜体与节点 rotation/skew。

描边文字分别读取 fill 与 stroke 的启用、颜色、宽度、对齐和透明度；`fill_opacity=0` 或 fill 禁用不能误判为有填充。

## P4.3 填充、形状与效果

逐层读取纯色/图片 fill、crop、渐变类型/向量/stop、圆角、边框、渐变描边、内外阴影、blur、effect stack、分层 opacity、blend mode、pass-through、纹理和低透明装饰。复杂渐变描边准备四角与上下左右中点共 8 点边缘采样。

## P4.4 蒙版、布尔与变换

登记蒙版节点、被遮罩子层、clip、布尔类型与最终边界、图片 crop、旋转、镜像、负缩放和变换矩阵。隐藏、裁掉或布尔减去的内容不得重新显示。

## P4.5 复杂视觉专项

单独盘点背景插图/半露出元素、嵌套 blur/柔光、卡片混合还原、按钮结构、角标锚点和 Figma 默认交互。记录父级裁切、真实锚点、offset、overlap、层级和最小完整视觉组。
