# 第一阶段完整报告扩展

仅在 `report_profile=full` 时与 `04-第一阶段数据契约.md` 一起加载。

## F1 逐节点字段

每个图层节点记录 ID、名称、类型、可见性、父级、子级顺序、section、角色、bbox、Auto Layout/约束、组件/实例/变体/override/变量、fill、stroke、corner、effect、opacity、blend、mask、boolean、clip、crop、transform、实现分类和证据。

每个文本层记录：

```json
{
  "layer_id": "",
  "content": "",
  "box_bounds": {},
  "visual_bounds": {},
  "line_count": 0,
  "wrap_positions": [],
  "font_family": "",
  "font_size": 0,
  "font_weight": "",
  "line_height": 0,
  "letter_spacing": 0,
  "alignment": "",
  "font_style": "normal",
  "rotation": 0,
  "skew": null,
  "fill": {},
  "stroke": {},
  "effect_stack": [],
  "text_runs": [],
  "restore_strategy": "real_text | svg_asset | png_asset",
  "why_not_real_text": null
}
```
