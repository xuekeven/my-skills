# 响应式组件规则与验收参考

## 组件决策顺序

1. 先判断父容器可用空间和设计锚点；
2. 再判断内容是否允许换行、增高或重排；
3. 最后确定图片/装饰是否按比例缩放、裁切或保持固定尺寸。

优先使用正常文档流、flex/grid、`min/max-width`、`clamp` 和局部绝对定位。绝对定位元素必须相对最近的语义容器，不能用页面级坐标复制所有宽度。

| 组件 | 默认策略 | 必须确认 |
|---|---|---|
| 页面容器 | 流式宽度 + 最大内容宽度 + 固定内边距 | 超范围行为、左右留白 |
| 文本卡片 | 宽度随父容器，高度随内容 | 最小宽度、换行、长文案 |
| 按钮组 | 保持点击区域，空间不足时按计划换排 | 换排断点、是否允许滚动 |
| 人物/装饰组合 | 相对所属卡片锚定并保持比例 | 可越界区域、裁切上下文 |
| 异形外壳 | 固定端部、只拉伸有证据的中段 | 是否存在可伸缩中段 |
| 固定底部操作区 | 固定定位或容器内锚定 | 短视口遮挡、滚动行为 |
| 长页面 | 自然增高和纵向滚动 | 不能锁死高度或静默裁切 |

## 多 viewport 证据

没有设计参考的 viewport 只能验证适配合同，不生成“像素还原率”。捕获 JSON 建议包含：

```json
{
  "width": 375,
  "height": 812,
  "kind": "base | min | max | middle | breakpoint_before | breakpoint_after | out_of_range",
  "status": "pass",
  "root": { "width": 375, "height": 1200, "natural_height": true },
  "checks": {
    "root_scale_used": false,
    "horizontal_overflow": false,
    "core_content_clipped": false,
    "console_error_count": 0,
    "network_failure_count": 0,
    "default_state_passed": true
  },
  "screenshot": "responsive/375x812.png",
  "capture_report": "responsive/375x812-capture.json"
}
```

应报告实际检查的 viewport 列表与未检查的计划项；“连续检查”必须说明采样步长或自动化方法，不得用几张截图声称覆盖所有连续宽度。
