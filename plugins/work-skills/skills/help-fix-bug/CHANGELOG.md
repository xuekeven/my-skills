# Changelog

## 2026-07-06

- 调整“了解 bug”阶段的问题顺序：先询问 bug 所在基线，再询问 bug 详细描述，最后询问 bug 出现时间。
- 当用户对 bug 出现时间留空且描述中包含禅道 / Jira / 前端监控警告报告链接时，不在“了解 bug”阶段打开链接；先将出现时间记录为待提取，等进入 `analyze.md` 阶段打开报告链接时同步提取。
- 在 `analyze.md` 阶段读取报告链接时，同一次读取中补齐「bug出现」「创建日期」「创建时间」「创建于」「Created」「Created Date」等字段作为 bug 出现时间；若无法提取，则兜底使用今天。
- 明确同一个报告链接只打开一次，不为补齐 bug 出现时间提前或重复打开。
- 在总结文档模板的“概述”表格中新增“修复用时”字段。
- 保留总结模板中的“测试回归”章节命名。
