# 06 - 综合结论与行动建议

## 目标

把多篇有效用户帖、评论和辅助材料综合成符合主模式和评价目的的结论，不把非商品主题强行写成购买建议。

## 输入

- Markdown 报告草稿
- 已选择的模式模板
- 每篇有效用户帖的模式相关信号
- 跳过帖子列表及原因
- 主题名称、主模式、评价目的和关注维度

## 动作

按主模式汇总以下维度：

- 共同正面点
- 共同风险点
- 商品：价格区间、规格、功能效果、品控、售后、渠道和合规风险。
- 事件：时间线、可见事实、相互冲突的主张、公开回应、观点分布、影响和待核实事项；不能把帖子数量当作事实证明。
- 实体：正面/负面口碑、直接经历、能力或服务印象、争议、公开回应和样本局限；匿名传闻不能当成确定事实。
- 品类：共性体验、方案/品牌/价格段差异、使用场景、成本、兼容、安全、门槛、适合与不适合人群；不能用单一品牌代表整个品类。
- 时间/IP 范围对结论的影响
- 完整与部分完成帖的比例、单帖证据质量、跨帖结论置信度和主要不确定性
- 有效用户帖、辅助材料和重复来源链各有多少，辅助材料不得提升用户评价样本数量

## 最终输出

按 `references/topic-modes.md` 的结论语言输出：

- 商品：`可以买，但要满足...`、`谨慎买，除非...` 或 `不建议买，如果你在意...`
- 事件：说明当前可见讨论、主要争议和待核实事项，不下超出证据的确定结论。
- 实体：说明整体口碑倾向、直接经历与争议的证据边界，不对个人或机构作无依据定性。
- 品类：说明适合的场景、主要取舍和比较顺序，不把单一品牌体验泛化为品类事实。

综合结论必须写入所选模板的模式专属章节，不得沿用其他模式的固定措辞。例如事件报告不输出“可以买”，实体报告不输出品类选型矩阵。

## 必须补充

- 说明目标有效帖数量、实际看了几个有效用户帖和辅助材料。
- 说明候选帖数量、实时打开贴峰值、最多查看贴数量（累计）以及主要跳过原因。
- 说明停止采集原因：已达到目标有效帖，或最多查看贴累计达到 30 个后有效用户帖仍不足；后一种情况必须说明不足目标数量的原因。
- 说明是否按批次关闭过已处理帖子标签页；如关闭过，说明有效用户帖和辅助材料的 URL 已保留，可用于回看。
- 说明结论主要来自正文还是评论。
- 说明结论由多少个独立帖子相互印证；单帖或单条评论只能作为低强度信号，同一帖内的多条评论不算独立样本。
- 按 `references/topic-modes.md` 给出跨帖结论置信度并说明理由。
- 说明是否应用了时间/IP过滤。
- 说明跳过了哪些类型的帖子。
- 商品列出付款前检查项目；事件列出待核实事项和后续观察点；实体列出核验或交往前检查项目；品类列出选型检查项目。
- 明确声明本报告描述本次小红书可见样本，不代表平台整体用户、公众民意，也不替代事件事实核查。

## 产出

- 符合主模式的最终结论
- 决策、核验、观察或选型检查清单

## 完成标准

- 用户能明确知道当前证据支持什么、不支持什么，以及下一步如何核验或决策。
- 所有有效用户帖和辅助材料的原始 URL、来源角色、采集状态和单帖证据质量均已保留；如需回看，按 URL 重开且同时打开的回看页不超过 10 个。
