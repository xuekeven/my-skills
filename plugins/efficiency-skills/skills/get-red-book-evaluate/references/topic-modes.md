# 评价模式

## 模式选择

从用户目标中选择一个主模式；不要只按关键词表面匹配。

- `商品`：具体可购买的商品、型号、服务或套餐，重点是使用体验、价格、渠道和是否值得买。
- `品类`：一类物品、技术、行业方向或概念，例如新能源汽车、AI、智能家居，重点是共性体验、差异、适用场景和趋势。
- `事件`：可定位的社会热点、公共事件、争议或舆情，重点是时间线、事实与主张、观点分布和影响。
- `实体`：公司、品牌、机构、公众人物或其他可识别主体，重点是口碑、能力、争议、服务或公众形象。

如果一个请求同时涉及多个模式，先确定主问题：例如“买某品牌新能源汽车”以`商品`为主，“某品牌口碑”以`实体`为主，“新能源汽车怎么选”以`品类`为主。主模式无法判断时，只追问模式和评价目的，不要开始采集。

开始搜索前明确主题边界：事件尽量确定日期、地点或相关主体；实体尽量确定全名、行业/身份或常用别名；品类明确包含与排除的子类。存在明显同名或多义且无法消歧时，先询问用户。

实体模式只适用于公司、品牌、机构、公众人物及其他具有明确公共角色的主体。不要为普通私人个体汇总声誉、私人生活或可识别个人信息。

## 评价目的和搜索扩展

保留用户原始关键词，并为搜索结果页增加少量同义或意图词；每轮最多使用 3-5 个扩展词，避免把搜索范围扩得过宽。

### 商品

可按需要追加：`体验`、`避坑`、`缺点`、`价格`、`售后`、`对比`、品类专属维度。

### 事件

可按需要追加：`进展`、`时间线`、`原因`、`争议`、`影响`、`回应`、`复盘`。优先覆盖不同日期和不同观点，不把转述帖当作独立事实来源。

### 实体

可按需要追加：`口碑`、`评价`、`服务`、`作品`、`合作`、`争议`、`经历`。对公司或品牌可增加`售后`、`员工`、`产品`；对公众人物只采集公开身份和公开行为相关内容。

### 品类

可按需要追加：`体验`、`对比`、`适合谁`、`问题`、`趋势`、`成本`、`兼容`、`安全`。尽量覆盖不同品牌、方案、价格段和使用场景，不能用单一品牌样本代表整个品类。

## 有效帖标准

所有模式都必须满足：主题相关、内容有具体信息或清晰归因的观点、不是广告或引流、URL 不重复，并符合用户指定的时间/IP范围。只有表情、纯转发、无新增信息的重复评论和纯情绪起哄不算有效证据。

- `商品`：至少提供真实使用、价格/渠道、功能效果、缺点、售后或对比中的一项具体信息。
- `事件`：至少提供可定位的事实片段、标注来源的主张、当事人/机构公开回应，或具体有时间地点的现场体验；未经证实的内容须标为“待核实主张”。
- `实体`：至少提供与该主体直接相关的公开经历、服务体验、作品/产品事实或具体争议；匿名指控、私人信息和无法归因的传闻不能作为确定事实。
- `品类`：至少提供具体场景、可比较维度、长期体验、成本/兼容/安全信息或清晰的方案取舍；泛泛而谈的趋势口号不算充分证据。

## 证据分类

每条重要信息标记为：`页面可见信息`、`个人体验`、`明确归因的主张`、`评价/态度`、`推测/待核实` 或 `营销话术`。正文和评论分别记录，不把评价改写成事实，不把同一帖子里的多条评论当成独立样本。

事件、实体相关内容涉及争议、违法或伤害指控时，只能写成“某用户/某帖声称”，同时记录是否有公开回应或其他独立帖印证；不推断个人身份、动机、罪责或未公开的私人信息。

## 来源角色与辅助材料

为每篇帖子记录可见的来源角色：`普通用户`、`直接参与者/消费者/员工`、`当事人或官方账号`、`媒体/搬运或转述账号`、`未知`。只有页面有明确线索时才标注，不猜测隐藏身份或利益关系。

- 普通用户或明确披露关系的直接参与者帖子可以作为有效用户帖，但必须保留其关系标签。
- 当事人、官方账号、商家、品牌、公关或其他利益相关方的声明，如果与事件或实体分析直接相关，作为`辅助材料`单独记录，不计入独立用户评价样本。
- 纯搬运、重复转述或无新增观点的帖子不算独立样本；多篇帖子引用同一原始说法时，只算一个来源链。

## 跨帖结论置信度

单帖记录“证据质量”，跨帖结论另记录“结论置信度”，不要混用：

- `高`：至少 3 篇相互独立的有效用户帖对同一结论提供高/中质量支持，且重要反例或冲突已披露。
- `中`：至少 2 篇独立帖子提供支持，但样本场景较窄、观点明显分裂或仍有关键待核实项。
- `低`：主要依赖单帖、单条评论、同一来源链、低质量信息，或采集受页面限制。

小红书搜索结果受推荐、登录态、时间和地域影响。本报告只能描述本次可见样本，不能代表平台整体用户、公众民意，也不能替代事件事实核查。

## 结论语言

- `商品`：使用“可以买，但要满足…… / 谨慎买，除非…… / 不建议买，如果你在意……”并附付款前检查清单。
- `事件`：使用“目前可见讨论呈现…… / 证据不足，暂不下确定结论 / 主要争议集中在……”并附待核实事项和后续观察点。
- `实体`：使用“整体口碑偏正面/中性/负面，但…… / 适合关注……，不宜据此断言……”并附核验或交往前检查清单。
- `品类`：使用“值得考虑，但取决于…… / 适合……，不适合…… / 先比较……再决定……”并附选型检查清单。

除`商品`外，不强行输出购买建议；如果用户明确要求购买决策，再在对应主模式结论后增加购买相关部分。
